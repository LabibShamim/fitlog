## Project Name
FitLog 

## Short Description
FitLog is a modern workout management web app where users can browse different workouts, view workout details, save exercises, and create a personalized daily workout plan. It also tracks total exercises, workout duration, and calories.

## Technologies Used
Next.js
React.js
Tailwind CSS
JavaScript (JSX)
React Context API
JSON for workout data

## 5 Key Features
Workout Library – Browse workouts with images, muscle groups, duration, calories, and ratings.
Workout Details – View detailed information about individual exercises.
My Plan – Add workouts to a personalized daily workout plan.
Saved Workouts – Save workouts for later access.
Sorting & Tracking – Sort workouts by duration, calories, or rating and track total exercises, minutes, and calories.
